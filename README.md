# eliterubbishclearance.com

Website for Elite Rubbish Clearance Ltd — rubbish, house, garden and garage clearance across West and Central London.

Static site served by GitHub Pages on the custom domain in `CNAME`.

- `index.html` — the page (no build step)
- `img/` — photos and logos
- `404.html`, `robots.txt`, `sitemap.xml`, favicons
